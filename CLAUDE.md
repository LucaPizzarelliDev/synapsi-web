# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Next.js 16 — not the version you know

Next.js **16.4.5** + React **19.3**. APIs and conventions differ from older training data. Before non-trivial Next-specific work, check the local docs in `node_modules/next/dist/docs/` and heed deprecations (`AGENTS.md` is regenerated by `next dev` — commit it with your changes, don't fight it). Already relied on in `next.config.ts`:

- **`cacheComponents: true`** and **`partialPrefetching: true`** — be deliberate about dynamic vs. cached data.
- **Typed routes**: layouts/pages use generated globals `LayoutProps<"/path">` / `PageProps<"/path">` (e.g. `LayoutProps<"/portal">`), not hand-written prop types.
- Permanent redirects: `/hermia → /viseria` (product rename 2026-10-24) and the Italian → English URL switch (2026-11-10) — keep this pattern for future renames.

## Commands

Run these **inside `synapsi-web/`** (the workspace root `synapsi/` has no manifest): `cd synapsi-web`
first, or use `npm --prefix synapsi-web run <script>` for one-offs. Dependencies are **not**
installed by default — run `npm install` first, or `lint`/`tsc` fail with `command not found`.

```bash
npm install            # required once; node_modules is gitignored
npm run dev            # dev server (Turbopack) → http://localhost:3000
npm run build          # production build — the authoritative typecheck gate
npm run start          # serve the production build
npm run lint           # eslint flat config (next core-web-vitals + typescript)
npx tsc --noEmit       # typecheck — ONLY works after a build/dev has run
```

`tsc --noEmit` on a clean checkout fails with `Cannot find name 'LayoutProps'/'PageProps'`: those
are Next-generated route globals written to `.next/types/` (referenced by `tsconfig`). Run
`npm run build` (or `npm run dev`) first to generate them; `npm run build` is the real gate.

No test runner is configured — do not invent `npm test`. No Prettier/editorconfig — formatting follows ESLint and the surrounding code only.

## Architecture

One App Router app, no backend: a **public marketing site** and a **client-portal demo**, all Italian, all content from hardcoded TypeScript. There is no DB, API, auth, or data fetching.

### Routes — `src/app/`, two root layouts
- **`[lang]/`** — public site, bilingual (`it`, `en`). Root layout `[lang]/layout.tsx` sets fonts, `<html lang>`, skip-link, `Header`/`Footer`, and `generateStaticParams` for both locales. One page per product (`viseria`, `prismia`, `chimeria`, `iridium`, `sport`) plus `method`, `about`, `contact`, and the homepage `[lang]/page.tsx`.
- **URLs**: Italian has no prefix (`/viseria`), English is `/en/viseria`. `src/proxy.ts` rewrites unprefixed paths to `/it/...` and 308-redirects `/it/...` to the unprefixed URL. Build internal links with `localize(lang, "/path")` from `src/lib/i18n.ts`; never hardcode `/en`.
- **`portal/`** — client portal, Italian only, with its own root layout `portal/layout.tsx` (no site header/footer). `portal/login/` is a standalone login; everything else is under `portal/(area)/` wrapped by `PortalShell` (`src/components/portal/Shell.tsx`), marked `robots: noindex`. Sections mirror the products: `people` (+ `[id]`), `managers`, `organization`, `reports` (+ `[id]`), `account`.
- **URLs are English everywhere** (site, portal, console, query params, anchors) since 2026-11-10; copy stays Italian/English as usual. Old Italian URLs 308-redirect in `next.config.ts` — add a redirect there whenever a path changes.
- **`admin/`** — superadmin console for Synapsi staff. CRM cascade: company + deal (`companies`) → only when the deal is won, portal areas (`areas`) → users and roles **per area** (no global user list); plus audit log (`activity`); URL slugs in English, UI copy in Italian, own root layout `admin/layout.tsx` wrapped by `AdminShell` (`src/components/admin/Shell.tsx`), `noindex`. Deliberately looks different from the portal (dark `night` sidebar, "Console" chip, `ob` accent). Sample data in `src/lib/admin.ts`; the forms (`NewCompanyForm`, `NewAreaForm`, `AreaUsers`, `DealPanel`) do not save anything yet — no DB/auth exists.
- `app/global-not-found.tsx` (flag `experimental.globalNotFound`) handles unmatched URLs; `[lang]/not-found.tsx` handles `notFound()` inside the site. Fonts are shared via `app/fonts.ts`.

### Content and data — `src/content/` and `src/lib/` (edit here first for any content change)
- **`src/content/<page>.ts`** — all site copy, one file per page plus `shared.ts` (services, nav, header/footer strings, `codes`, `viseriaFactors`, `chimeriaCriteria` in Burke-Litwin order, `prismiaDimensions`, `methodSteps`, `notWeDo`, `team`) and `graphics.ts` (texts of the illustrative graphics). Each exports `{ it, en }`; `en` is typed as `typeof it`, so a missing translation is a type error. Add a string to both languages.
- **`src/lib/i18n.ts`** — `locales`, `Locale`, `localize`, `unlocalize` (client-safe). **`src/lib/locale.ts`** — `getLang()` (reads the `[lang]` root param, server only) and `pageMetadata(lang, path, meta)` (title, description, canonical + hreflang alternates).
- **`src/lib/site.ts`** — language-independent constants only: `contact`, `Code`, `codeBg`.
- **`src/lib/portal.ts`** — portal sample data + types: `Assessment`, `Report`, `prismiaCycles`, `checkups`, `activity`, `users`, `client`, `psychologists`, `stages`, and `formatDate`. Comments encode real product rules (e.g. Prismia consent gating) — preserve their meaning.

Site pages call `const lang = await getLang()` and read `content[lang]`; components that also render in the portal (`ScoutingCard`, `OrgMap`, the other graphics) take an optional `lang` prop defaulting to `"it"`. Client components (`Header`, `ContactForm`) receive their strings as props.
Pages render by mapping over these objects; they don't fetch. Changing copy/figures = editing `src/content` (both languages), not the JSX.

### Domain (needed to read the data)
Psychologist-led assessments with AI-assisted transcription/coding. Products read different levels: **Viseria** = a person in a role (Scouting Card) · **Prismia** = a manager via interview-based 360, consent-gated, development-only · **Chimeria** = the organization (12 Burke-Litwin areas) · **Iridium** = commercial networks. Four evidence codes — **OB** observable, **PS** pattern, **AC** competence, **IP** hypothesis — double as the brand palette.

## Conventions (match these before inventing new ones)

- **Exports**: pages → `export default` (Next requirement); components & `src/lib` helpers → **named exports**. See `src/components/ui.tsx`.
- **Server-first**: add `"use client"` only for interactivity. Today only `Header`, `ContactForm`, and portal `Shell`/`LoginForm`/`PeopleTable`/`ReportTable`/`PrintButton` are client. See `src/components/Header.tsx` for the client pattern (hooks + outside-click/escape).
- **Icons & graphics are inline SVG** — `src/components/portal/icons.tsx` (d-path registry) and `src/components/graphics.tsx`. No icon library, no emoji, no `next/image`/`<img>` anywhere.
- **Styling** is Tailwind v4 configured only in `src/app/globals.css` (`@theme` + `@utility`; no `tailwind.config`). Use the semantic tokens (`ink`, `body`, `cream`, `cream-2`, `sand`, `violet`, `violet-dark`, `night`, `lavender`, `line`, and `ob`/`ps`/`ac`/`ip`) and utilities (`display`, `marker`, `logotype`) — **never hardcode hex or ad-hoc colors**. The old names (`paper`, `paper-2`, `primary`, `primary-soft`, `frame`) remain only as aliases for the portal. Fluid type via `clamp()`. Fonts (`app/fonts.ts`): `--font-display` Gabarito, body Onest, `--font-mono` Spline (data, codes, IDs only).
- **Primitives first**: compose `Container`/`Section`/`Heading`/`Display`/`Button`/`Mark`/`CodeTag`/`DocFrame`/`DotGrid`/`CtaBand`/`PageIntro` from `src/components/ui.tsx` (plus `ProductGlyph`, `Logo`), and the portal equivalents in `src/components/portal/ui.tsx`, instead of re-implementing layout.
- **Accessibility is baseline, not optional** — the repo already does `aria-current`/`aria-expanded`/`aria-controls`, labelled nav landmarks, a skip-link, and `focus-visible` rings (`globals.css`). Keep that bar.
- **Italian first**: comments and portal copy are Italian (URL slugs are English); site copy exists in Italian and English (`src/content`). Copy is concrete and plain ("fatti, non opinioni" / "facts, not opinions") — see `src/content/home.ts`.
- Import alias **`@/* → src/*`**.

## Design & code quality

Since 2026-11-10 the site uses a warm, rounded visual language (inspired by komoot's layout, not its content): cream background, rounded tiles coloured with the four evidence codes, pill buttons, a full-screen dark hero, and graphics that show pieces of the method (interview, codes, report, signature). The user rejected both the earlier ink-hairline "referto" style and decorative stickers (flowers, bursts, waves) as off-theme. The main failure mode is generic AI-generated UI/code that breaks this language. Before writing UI, copy, or non-trivial code, follow:

@.claude/rules/anti-ai-smell.md

## Verifying UI

Use the **`nuova-sezione`** skill when scaffolding pages/sections/components, and the
**`design-review`** skill to review UI against the rules above. For real (not just static)
verification, start the dev server (`npm run dev`) and let `design-review` drive the
**Playwright MCP** to open `http://localhost:3000`, screenshot pages, and check focus/contrast.
